[NOTES for hgshadow use]
If you want the Softer self-shadows, I've included the hgshadow effect in the ShaderFX folder for you to use. Just load the x file in mmd and it should work right away. (without it; the shadows will look jagged and depend on mmd shadow system)
There's a shader controller in the ShaderFX folder as well for you to play around with.
The shadow issue for the nose can be fixed by disabling it in the MME effect tab "HgS_VMap"
